# My Radio Setup

## Overview
Details of the software I use for radio, what it is used for, tips for installing and configuring and more.

### wfview
Open Source ham radio interface (Meant for Icom and Kenwood). Allows me to control my X6100 over a network. 
- Website: [wfview](https://wfview.org/)

### WSJT
FT8 Client
- Website: [WSJT](https://wsjt.sourceforge.io/wsjtx.html)

### NanoVNA-Saver
Allows me to connect and work with my NanoVNA from the computer rather then the screen itself. 
- Website: [NanoVNA-Saver](https://github.com/NanoVNA-Saver/nanovna-saver)

### Direwolf
A Terminal Node Controller (TNC) to interface to my radios for APRS.
- Website: [Direwolf - Github](https://github.com/wb2osz/direwolf)

### PinPoint
APRS client
- Website: [Pinpoint](https://www.pinpointaprs.com/)
